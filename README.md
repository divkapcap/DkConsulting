4# RetailCo Profitability Challenge 

## Overview/Background
This project analyzes RetailCo's profitability performance from January 1, 2026 - June 30, 2026 using a retail
operations dataset that was provided to our team. The main objective is to:
- identify the factors driving the gap between revenue growth and profitability
- evaluate impacts across key stakeholder groups
- develop actionable recommendations

## Business Problem
RetailCo has observed that their revenue is growing but their profit has not.

The goal of this project is to close that gap and answer the following questions:

1. What is driving RetailCo's profitability challenge?
2. What evidence supports these findings?
3. How do these issues affect key stakeholders?
4. What actions should RetailCo take next?
5. What assumptions and limitations impact the analysis?
6. What additional information should be requested before implementing recommendations?

## Dataset
This project uses 6 datasets provided to us by the company (aka Connor)
1. customers.csv - customer demographics, geography, and more
2. products.csv - product catalog info, categories, pricing, and costs
3. orders.csv - order info (promotions, shipping revenue, and more)
4. order_items.csv - product info (quantity, discounts, and more)
5. fulfillment.csv - shipping costs, delivery status, and warehouse data
6. returns.csv - return transactions, amounts, and also cutsomer reasoning for returning the items
